3. score_ecs.py
  PY -I -B score_ecs.py [--out <ECS>/score] [--no-power]  -> score.json, score.txt; exit 0 final, 3 provisional or
  incomplete, 2 input error.
  Classes from check.json, read.json (R1), lost.json: LOST (lost.json, or R1's C6 counting failures even before
  lost.json has it); COUNTED (stop "end" at E); STOPPED (stop "collapse", S < T < E), POSITIVE or CENSORED; otherwise
  undecided. Records that disagree (name/start/arm/seed/S/E/T, a read.json bound to another check.json's sha256, a
  passing check with another stop reason, a lost.json name outside the queue) are input errors.
  INCOMPLETE while any of the 24 is undecided or a decided one has no R1 read: no line, no table, no p, no outcome word
  is printed (tested); the undecided are listed with any kept _void/_crashed folders ("VOID until fixed").
  Tables: as counted (known outcomes only); filled against B LOWER (arm A missing -> NEGATIVE, arm B missing ->
  POSITIVE) for P_UP; filled against B HIGHER (the reverse) for P_DOWN; missing = LOST or CENSORED. The exact test is
  table_e_ecs.py's stratum_null / null_T / pvals / binom / power, moved unchanged in arithmetic; SIDE = Fraction("0.025")
  = 1/40 from ecs_common.ALPHA_PER_SIDE, so the 0.025 line is decided exactly.
  The line (first that applies), its texts verbatim from criteria v2: 1 B LOWER, 2 B HIGHER, 3 NO DIFFERENCE DETECTED
  (followed by each start's "arm A a of 6, arm B b of 6"), or the NOT INFORMATIVE variant when both starts carry a LOW
  ARM-A RATE or NO ARM-A note; with "(B LOWER [B HIGHER] holds only without the n LOST or censored continuations)" when
  that line holds on the table as counted (unequal arms, same test) but not filled. Printed beside: both tables per
  start, P_UP and P_DOWN as exact fractions (filled; as counted, report only), the per-start notes, one-sided Fisher p
  both ways per start (as counted and on the fills; report only), TABLE E's power figures (recomputed), every STOPPED /
  CENSORED / LOST continuation with its cause, and one report-only line per continuation (first ANY flag or "none,
  censored at T", flagged count, ANY/TAIL alarms, TAIL-flagged, TAIL-input-missing count, std first/last, mean return,
  R3 CMD tail_3 / tail flags / falls).
  R3 is read by the scorer itself at score time (R.trace_reading on <ECS>/traces/<name>), because run_waves_ecs.sh runs
  the full reads (R1/R2) before it makes the end traces [measured, run_waves_ecs.sh l340-l392].
  PROVISIONAL (printed, not acted on; exit 3) while any of: no <ECS>/APPROVED; no criteria.txt; criteria.txt's sha256
  != APPROVED's criteria_sha256 (APPROVED read as JSON with ecs_common.APPROVED_KEYS; a text APPROVED is read line by
  line); APPROVED code_tree_digest != the pin; any ecs_common.TOOL_FILES entry without a tool_sha256 pin; any pinned
  file (APPROVED tool_sha256, <ECS>/SHA256SUMS.txt) differing; M1/M5 pins (ecs_common.check_pins); a check.json or
  read.json made by another read_ecs.py than the current; R1 run with another M5; a continuation whose run_meta
  criteria sha256 or tool_sha256 differs from criteria.txt / the pins; the code copy's seal tree_digest. It clears only
