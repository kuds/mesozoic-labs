2. THE ONE TEST (task item 2)
 - Statistic unchanged (TD: the whole-run mean of |CMD_L|); the comparator is now the 3 OFF runs: the exact one-sided
   3-vs-3 permutation test over 20 splits, phase LOWER, ties against H1, minimum p 1/20, alpha 0.05; LOWER only on
   complete separation (every phase TD below every OFF TD). Text "LOWER THAN EVERY CONCURRENT SWITCH-OFF RUN (exact
   permutation p = 1/20)" or "NOT SEPARATED (p = k/20)".
 - MISSING against H1: a phase seed without a COMPLETE and FINISHED run enters at +infinity (highest rank); an OFF seed
   likewise at -infinity (lowest rank), and so does an OFF run that is not blind (section 4). Why a rule for sums with
   infinities was needed: the reviewed rule had only one side missing (+infinity on fixed finite comparators, so every
   split holding it "tied" and p was 20/20); with both sides able to miss, +inf and -inf can meet in one split. The
   amended order is the limit of +M / -M for a large M: a 3-sum is (number of +inf minus number of -inf, exact finite
   sum), compared lexicographically. Consequence [measured, tests]: any missing run gives k >= 11 (never LOWER); one
   missing phase run on otherwise separated values reads 11/20 where the reviewed rule read 20/20 -- both NOT
   SEPARATED, the only reading that decides anything (LOWER) is unchanged. Checked against an independent +M/-M
   Fraction oracle on 400 random mixes (test_one_test_missing_ranks_against_an_oracle) and refused for wrong-side
   infinities or NaN.
 - Honesty line (criteria, scorer note): TD's form was chosen with STANCE6's values in view (2 windows looked at); the
   six runs' values, the OFF runs' included, are unseen at the pin. The reviewed "strict bound of 2/20" sentence is
   dropped: it bounded a choice made on the comparators' own values; the test data are now new runs, so the choice is
   fixed before its data [inferred].
 - Caveat line rewritten: concurrent control, exchangeability assumed up to seed effects (each phase run and its
   same-seed OFF run start from the same network, A5 measured: the first rollout bitwise switch ON vs OFF), a positive
   within-seed dependence making the unpaired test conservative [inferred: a shared start can only add a shared
   component]; GPU nondeterminism within today's image remains. The paired sign test still cannot go below 1/8.
 - STANCE6 report only everywhere it was a comparator: THE COMPARATORS section renamed "STANCE6, REPORT ONLY"; the
   test's stance6_report_only TDs printed beside; Statistic A beside; per seed beside; the line-1 first TAIL ALARM
