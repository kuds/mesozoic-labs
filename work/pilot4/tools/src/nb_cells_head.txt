# Mesozoic Labs — Stable-Baselines3 Training

Train one model's behavior chain (a species in one embodiment) with PPO or SAC. `BEHAVIOR` names a deliverable (a recipe label — `stance`, `recover`, `walk`, `hunt` — or a stage id), and one loop walks its chain from the model's stage manifest, root first: each node is REUSED when this run or, for an ancestor, the trunk run (`TRUNK_FROM`) holds a certified copy, JUDGED when it was trained but never gated, and TRAINED from its parent's handoff otherwise (`docs/BEHAVIOR_RECIPES_PLAN.md` §4.7; the [behavior recipes guide](https://github.com/kuds/mesozoic-labs/blob/main/website/docs/training/recipes.md#in-the-notebook) has the detail). The run directory (on Drive in Colab) keeps the checkpoints, verdict and artifacts of every node this run trains or judges, and its bundle publishes the certified ones; an ancestor reused from the trunk is only recorded under `ancestors/` and is loaded from the run that certified it.

Budgets, environment settings and hyperparameters come from the stage TOMLs that `configs/<species>/<embodiment>/stages.toml` names; this notebook does not copy them. Smoke-test with `QUICK_TEST`; for a full run keep the configured values and size `N_ENVS` from the memory and throughput you observe (no hardware table is published).

## 2. Configuration

`SPECIES` (one of the five species IDs) and `EMBODIMENT` (`anatomical` or `robot`) select the model by its exact IDs in `configs/species_manifest.toml` ([species naming](https://github.com/kuds/mesozoic-labs/blob/main/docs/SPECIES_NAMING.md)). Six pairs are models: the `anatomical` model of every species and the `robot` of `compsognathus_longipes`. Any other pair, an alias or a display name is refused before anything is written (decision D-D33), and runs live under `<LOG_BASE>/<species>/<embodiment>/`. The Compsognathus pair's policies read simulator state, not the head camera, and cannot be deployed as-is on the robot ([training guide](https://github.com/kuds/mesozoic-labs/blob/main/environments/compsognathus_longipes/README.md#training)). Each knob's comment says what its values do; these decide what a session writes:

- `BEHAVIOR`: the deliverable, a recipe label or a stage id. `"stance"` is the stance stage alone on every model (the stage's id and its recipe label are the same name; `"stand"`, its label until decision D-D38, is refused with a pointer to `"stance"`); `"recover"` is stance → push recovery, whose frozen gate is then enforced, and exists on the T. rex and both Compsognathus models (decision D-D35: before it the stance label meant that chain on those three); `"walk"` is stance → locomotion; `"hunt"` (the default) is stance → locomotion → the species task. A stage id is accepted too and trains that stage's chain.
- `TRUNK_FROM`: `"auto"` (D-A25) reuses the certified ancestors of the run of this model and algorithm that covers the most of the chain, the greatest run directory name on a tie (a custom `RUN_ID` such as `my_run` sorts after every timestamp); a run id (or an absolute run directory) pins one; `""` trains every node here. The target node is never reused across runs, and the resolve cell prints the choice and the runs it refused (the first 20; `TRUNK_SELECTION.candidates` holds every run scanned).
- `RUN_ID`: `""` keeps the run this runtime resolved last in the tree `SPECIES`, `EMBODIMENT`, `ALGORITHM` and `QUICK_TEST` select, or mints a fresh one; a new id starts a fresh run; an existing id re-enters that run to finish an interrupted or `partial` run (section 5); re-run the storage cell after changing it. A recorded node is never overwritten and a `complete` run takes no new node, so a new variant is a new `RUN_ID`.
- `QUICK_TEST`: a pipeline check, 50,000 steps a node (it may stop at a gate), written under `<algorithm>_quick_test/`: never a trunk or a seed replicate of a real run, though it can reuse real certified ancestors.

def train_stage(
    stage,
    timesteps,
    *,
    load_path=None,
    run_dir,
    vecnorm_path=None,
    task_load_mode,
    parent_run_id=None,
    label=None,
    eval_freq=50_000,
    save_freq=100_000,
    evaluate=True,
):
    """Train one node of the behavior chain with ``train_base.train``, the CLI's trainer, then evaluate it.

    ``run_dir`` is required: a node trains only into a run directory.
    ``task_load_mode`` is REQUIRED and never inferred. The chain loop passes
    ``"initialize_next_stage"`` when the node loads its parent's handoff
    (its declared edge, recorded as lineage) and ``"resume_same_stage"`` for
    a root that loads nothing; the RESUME cell passes ``"resume_same_stage"``
    for a load of this node's OWN periodic checkpoint. A checkpoint and its
    VecNormalize sidecar always travel together. ``parent_run_id`` names
    the run a reused certified ancestor came from (``None`` for a parent
    trained in this run); ``label`` is the free-text run label recorded
    beside the hyperparameter digest (decision D-A21). What ``train`` refuses
    and records, and the two switches passed here, are in its docstring; the
    gate is judged afterwards by ``generate_stage_artifacts`` and enforced by
    the chain loop. ``evaluate=False`` (the RESUME cell) skips the evaluation
    of the final and selected checkpoints (up to 60 episodes): the chain
    loop's JUDGE branch evaluates that node from disk before anything
    certifies it.

    Returns (model, best_model_path, final_model_path, stage_dir, vecnorm_save_path, stage_results); without the
    evaluation, (model, None, final_model_path, stage_dir, None, None).
    """
    from environments.shared.stage_manifest import stage_display_name

    NODE = MANIFEST.resolve(stage)
    if task_load_mode not in ("initialize_next_stage", "resume_same_stage"):
        raise ValueError(
            "task_load_mode must be declared as 'initialize_next_stage' (the parent's handoff) or "
            f"'resume_same_stage' (this node's own checkpoint, or nothing), not {task_load_mode!r}"
        )
    if bool(load_path) != bool(vecnorm_path):
        raise ValueError(
            "load_path and vecnorm_path must be given together: a checkpoint is only ever loaded under "
            "the VecNormalize statistics it was trained with"
        )
    if task_load_mode == "initialize_next_stage" and not load_path:
        raise ValueError(f"{NODE.id!r}: 'initialize_next_stage' declares a load from the parent's handoff, but no load_path was given")
    if task_load_mode == "initialize_next_stage" and NODE.warm_start_from is None:
        raise ValueError(
            f"{NODE.id!r} is a root of the {MODEL_ID} manifest (no warm_start_from), so it cannot enter from a "
            "parent under 'initialize_next_stage'; a root trains from scratch or resumes its own checkpoint"
        )
    if vecnorm_path and not Path(vecnorm_path).is_file():
        # Refused here, before train() writes the stage config, so a corrected re-run is not an occupied directory.
        raise FileNotFoundError(
            f"VecNormalize sidecar not found: {vecnorm_path}. Refusing to train the loaded checkpoint under "
            "fresh normalization statistics."
        )
    # Directory names sort in curriculum order and carry the id (01_stance,
    # 02_recovery, ...); files inside keep their stage_label prefixes.
    stage_dir = Path(run_dir) / stage_dirname(MODEL_ID, stage)
    config = STAGE_CONFIGS[stage]
    print(f"{'=' * 60}")
    print(f"Node {NODE.id} (stage {stage}): {stage_display_name(stage, config['name'])} ({ALGORITHM})")
    print(f"Description: {config['description']}")
    print(f"Timesteps: {timesteps:,}")
    print(f"Log dir: {stage_dir}")
    if vecnorm_path:
        print(f"VecNormalize loaded from: {vecnorm_path}")
    print(f"{'=' * 60}")

    model = train_base.train(
        SPECIES_CFG,
        STAGE_CONFIGS,
        stage,
        timesteps,
        n_envs=N_ENVS,
        seed=SEED,
        load_path=load_path,
        vecnorm_path=vecnorm_path,
        eval_freq=eval_freq,
        save_freq=save_freq,
        verbose=VERBOSE,
        algorithm=ALGORITHM.lower(),
        output_dir=str(stage_dir),
        task_load_mode=task_load_mode,
        parent_run_id=parent_run_id,
        label=label,
        report_metrics=False,
        save_on_interrupt=False,
        k3_panel=k3_panel_config(),
    )
    final_path = stage_dir / "models" / f"{stage_label(stage)}_final"
    print(f"\nFinal model saved to: {final_path}.zip")

    # Without the evaluation: the trained model and its final path, and None for what only the evaluation
    # selects or measures (the handoff pair and stage_results).
    _model, _handoff_stem, _final_model_path, _handoff_vecnorm, _stage_results = (
        model, None, str(final_path), None, None
    )
    if evaluate:
        _model, _handoff_stem, _final_model_path, _handoff_vecnorm, _stage_results = evaluate_stage_checkpoints(
            SPECIES_CFG,
            config,
            stage,
            ALGORITHM,
            stage_dir,
            final_path=final_path,
            final_vecnorm_path=f"{final_path}_vecnorm.pkl",
            timesteps=int(model.num_timesteps),
            duration_seconds=read_stage_duration(stage_dir),
            plant_identity=PLANT_IDENTITY,
            evaluation_seed=EVALUATION_SEED,
            model=model,
        )
    return _model, _handoff_stem, _final_model_path, stage_dir, _handoff_vecnorm, _stage_results

                "that resume's final save replaces the broken pair."
            )

            # during the final save, leaves a spent budget with no intact final pair, which the
            # chain loop's JUDGE branch needs.

                "the chain loop's JUDGE branch cannot judge it and there is nothing left to train: train the node "
                "again in a fresh RUN_ID, with TRUNK_FROM naming this run for its certified ancestors."
            )
        else:

            refuse_write_into_complete_run(RUN_DIR, what=f"Resuming {stage_res!r}")
            # Nor a node the run holds as an ancestors/ record, nor under another trunk than trunk_run.json records
            # (decision 4 (a); docs/KNOWN_ISSUES.md for cells run out of order): this refusal writes nothing either.
            refuse_trunk_other_than_recorded(

                resumed=entry_res,
            )
            model_res, path_res, final_path_res, dir_res, vecnorm_res, results_res = train_stage(
                stage=stage_res,
                timesteps=remaining_res,
                load_path=str(ckpt_res),
                run_dir=RUN_DIR,
                vecnorm_path=str(vecnorm_ckpt_res),
                task_load_mode="resume_same_stage",
                label=RUN_LABEL or None,
                evaluate=False,  # the chain loop's JUDGE branch evaluates the node from disk
            )
##### CELL 19 [markdown]
## 6. Train the behavior chain

One loop walks `BEHAVIOR`'s chain root first and, for each node, does exactly one of:

1. **Reuse** a certified checkpoint from this run or, for an ancestor, from the trunk run, when the reuse rule holds: a passed gate verdict, the same task digest and plant, and a checkpoint that descends from the parent resolved here. A cross-run ancestor is recorded under `ancestors/` (JSON records, never the checkpoint pair) and loaded from the run that certified it.
2. **Judge** a node that was trained but never gated (an intact final pair and no `gate_verdict.json`: the RESUME cell finished it, the runtime stopped before its verdict, or the command-line widen tool wrote a widened root here). Such a node is never replaced by a trunk's copy: the trunk is not consulted for it, and it is judged only on the parent it was trained from (decision 6 (b), amending D-A17 and D-C13); a run that already holds the trunk's copy of it as an `ancestors/` record keeps that record.
3. **Train** it otherwise, from its parent's handoff pair along the declared edge (`initialize_next_stage`; a root loads nothing). A frozen-null gate kind (recovery) freezes its thresholds and null panels **before** training and rolls the policy panel after, on the same seeds.

Every trained or judged node writes its artifacts, the training summary and the run bundle **before** its verdict is enforced, so a failed gate still publishes every certified deliverable above it; the runtime is then released and the loop raises. A write into a `complete` run that the resolve cell could not predict is refused here; the node goes into a fresh `RUN_ID` trunked from that run.

    # above a failure is published (result schema v4: the bundle is `partial`).
    write_training_summary(RUN_DIR, chain_results())
    save_run_bundle(chain_results(), model_id=MODEL_ID)

    # Enforce the recorded verdict. halt releases the runtime, then raises: the raise
    # stops "Run all", so the auto-disconnect cell at the end would never execute.
    if not results["publication_gate_passed"]:
        _gate_msg = f"{NODE.id} failed its curriculum gate: " + "; ".join(results["gate_failures"]) + "."
        halt(_gate_msg, in_colab=IN_COLAB, auto=AUTO_DISCONNECT, flush_drive=USE_GOOGLE_DRIVE)
    print(f"{NODE.id}: gate PASSED ({gate_kind}); handoff {handoff_stem}.zip")
    NODE_HANDOFF[NODE.id] = {
        "model": handoff_stem,
        "vecnorm": handoff_vecnorm,
        "stage_dir": stage_dir,
        "run_dir": RUN_DIR,
        "run_id": None,
        "model_sha256": sha256_file(f"{handoff_stem}.zip"),
        "normalization_sha256": sha256_file(handoff_vecnorm),
        "reused": False,
    }
##### CELL 21 [markdown]
## 7. Manual single node (debugging escape hatch)

Train ONE node outside the chain — to probe a config, or to rerun a node from an arbitrary checkpoint — by setting `MANUAL_NODE` below, with its load edge declared: `MANUAL_LOAD_MODE = "initialize_next_stage"` for a parent's handoff, `"resume_same_stage"` for this node's own checkpoint. The verdict is recorded into the summary and bundle but **never enforced**, and nothing downstream trains on the node. A `complete` run takes no manual node. Leave `MANUAL_NODE = None` for an unattended Run all.
##### CELL 22 [code]
# ===== MANUAL SINGLE NODE — debugging escape hatch =====
MANUAL_NODE = None  # None = skip; a stage reference (2 or "recovery") to train ONE node outside the chain
MANUAL_LOAD_PATH = None  # checkpoint stem to load (None = from scratch); its sidecar goes in MANUAL_VECNORM_PATH
MANUAL_VECNORM_PATH = None
MANUAL_LOAD_MODE = "initialize_next_stage"  # the load's declared edge: a parent's handoff, or "resume_same_stage"
MANUAL_TIMESTEPS = None  # None = the node's TOML budget (QUICK_TEST shortens it)

if MANUAL_NODE is not None:
    from environments.shared.curriculum import FROZEN_NULL_GATE_KINDS
    from environments.shared.harnesses.freeze_recovery_gate import (
        freeze_recovery_gate,
        roll_policy_panel,
        validate_recovery_resolution,
    )
    from environments.shared.recovery_evaluation import write_recovery_evidence
    from environments.shared.result_bundle import ResultBundleError, refuse_write_into_complete_run

    _manual_entry = MANIFEST.resolve(MANUAL_NODE)
    # A complete bundle is immutable: refused here, before the freeze or the training below writes anything.
    refuse_write_into_complete_run(RUN_DIR, what=f"The manual node {_manual_entry.id!r}")
    _manual_stage = _manual_entry.reference
    _manual_config = STAGE_CONFIGS[_manual_stage]
    _manual_dir = Path(RUN_DIR) / stage_dirname(MODEL_ID, _manual_stage)
    _manual_gate_kind = _manual_config.get("curriculum_kwargs", {}).get("gate_kind")
    _manual_budget = MANUAL_TIMESTEPS or node_budget(_manual_stage)
    _manual_policy_zip = f"{MANUAL_LOAD_PATH}.zip" if MANUAL_LOAD_PATH else None

    # A frozen-null kind (recovery) pre-registers its gate before training,
    # exactly as the chain loop does.
    if _manual_gate_kind in FROZEN_NULL_GATE_KINDS and not (_manual_dir / "gate_resolution.json").exists():
        print(f"Freezing the {_manual_gate_kind} resolution for {_manual_entry.id!r}...")
        freeze_recovery_gate(
            _manual_dir,
            model_id=MODEL_ID,
            stage=_manual_stage,
            policy_zip=_manual_policy_zip,
            vecnorm=MANUAL_VECNORM_PATH,
            algorithm=ALGORITHM,
        )
    if _manual_gate_kind in FROZEN_NULL_GATE_KINDS:
        validate_recovery_resolution(
            _manual_dir,
            model_id=MODEL_ID,
            stage=_manual_stage,
            policy_zip=_manual_policy_zip,
            vecnorm=MANUAL_VECNORM_PATH,
            algorithm=ALGORITHM,
        )

    _manual_model, _manual_handoff, _manual_final, _manual_dir, _manual_vecnorm, _manual_results = train_stage(
        stage=_manual_stage,
        timesteps=_manual_budget,
        run_dir=RUN_DIR,
        load_path=MANUAL_LOAD_PATH,
        vecnorm_path=MANUAL_VECNORM_PATH,
        task_load_mode=MANUAL_LOAD_MODE if MANUAL_LOAD_PATH else "resume_same_stage",
        label=RUN_LABEL or None,
    )

    _manual_panel = None
    if _manual_gate_kind in FROZEN_NULL_GATE_KINDS:
        _manual_evidence = roll_policy_panel(
            _manual_dir,
            f"{_manual_handoff}.zip",
            _manual_vecnorm,
            model_id=MODEL_ID,
            stage=_manual_stage,
            algorithm=ALGORITHM,
        )
        write_recovery_evidence(_manual_dir, _manual_evidence)
        _manual_panel = _manual_evidence.successes_by_seed()

    _manual_results = generate_stage_artifacts(
        species_cfg=SPECIES_CFG,
        stage_config=_manual_config,
        stage=_manual_stage,
        algorithm=ALGORITHM,
        stage_dir=_manual_dir,
        seed=SEED,
        stage_results=_manual_results,
        recovery_successes_by_seed=_manual_panel,
    )
    NODE_RESULTS[_manual_entry.id] = _manual_results
    completed_stages.append((_manual_stage, _manual_dir))
    display_stage_videos(_manual_dir)

    # Recorded, never enforced: this cell is a probe, not a chain step, so no
    # raise and no disconnect — and it never feeds NODE_HANDOFF.
    if _manual_results["publication_gate_passed"]:
        print(f"{_manual_entry.id}: gate verdict PASS ({_manual_gate_kind})")
    else:
        print(f"{_manual_entry.id}: gate verdict FAIL ({_manual_gate_kind}) —", "; ".join(_manual_results["gate_failures"]))

    try:
        write_training_summary(RUN_DIR, chain_results())
        save_run_bundle(chain_results(), model_id=MODEL_ID)
    except ResultBundleError as exc:
        # Never swallowed silently (D-A11): a manual node that the bundle
        # cannot place (e.g. its parent is not in this run) is reported.
        print(f"Result bundle not rewritten for the manual node: {exc}")
