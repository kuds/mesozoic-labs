# M3 production candidate — planned

Build from the accepted M2 revision. Freeze selected parts and toleranced
drawings, connectors, wiring harness, fasteners, assembly sequence, battery
access and repair procedures. Use an independent repeat build to check that
the documented process produces comparable mechanics and behavior.

Acceptance records identify hardware/firmware/calibration revisions and device
serials, assembly measurements, endurance/thermal results and the repeat-build
behavior panel. Version the final model and its policies through the same plant
contract. A production candidate becomes a release only after those records
support it; this folder currently contains a plan, not a finished design.
