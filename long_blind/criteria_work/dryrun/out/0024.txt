     1	#!/usr/bin/env bash
     2	# LB: BS2's run_waves_bs.sh (S2/r10round/bias_screen2/tools/run_waves_bs.sh, sha256 6e0484f6...) with the root changed
     3	# (BS_REAL = S2/r10round/long_blind) and these LB changes; "<BS>" below = LB:
     4	#   RESUME a crash that is one of its own is rerun at once with --resume-from <its retired runs/<name>_crashed<k>>:
     5	#          run_bs.py resumes from that attempt's newest complete saved pair (bs_resume.resume_point), or starts again
     6	#          from S when it has none (BS2's rerun).  A relaunch finds the folder in logs/crash_ledger.tsv.  The early
     7	#          crash rule counts from the attempt's load step (run_meta load_step: S, or the resume point).
     8	#   HOP    a continuation the stage's hop watch stopped (CHECK passed, stop reason "hop_watch") is STOPPED, like
     9	#          "collapse".
    10	#   RR-1   a relaunch after ALL_DECIDED keeps the first logs/atimes_at_ALL_DECIDED.tsv; a later snapshot goes to
    11	#          logs/atimes_at_ALL_DECIDED.relaunch<k>.tsv.
    12	#   I1     right after each attempt exits, before CHECK and the re-arm, logs/atimes_at_exit/<name>.attempt<k>.tsv
    13	#          records path, atime, mtime and ctime (lstat only) of runs/<name>/**, tmp/<name>/** and the attempt log.
    14	#   SCORER the scorer the APPROVED pin must name is bs_common.SCORER_FILE (score_bs.py).
    15	# The queue mechanics, slots, nice, floors and the outcome-blind reads are BS2's, unchanged.
    16	# BS2 review fixes (the fixer, 2026-10-30; <BS2>/review/FIXES.txt), additions only:
    17	#   PR-M4  the runner refuses (exit 2, nothing started) unless APPROVED's tool_sha256["score_bs.py"] equals the current
    18	#          tools/score_bs.py (run_bs.py's preflight pins the five bs_common.TOOL_FILES only);
    19	#   PR-M2  lesson P4 (relatime): right after a continuation is decided COUNTED or STOPPED, every regular file under
    20	#          runs/<name>/ and tmp/<name>/ and its logs/<name>.attempt<k>.log is re-armed (atime = mtime - 1 ns; content,
    21	#          mtime and sha256 unchanged), so any later read of one moves its atime; at ALL_DECIDED, before
    22	#          logs/ALL_DECIDED is written and before the full reads, logs/atimes_at_ALL_DECIDED.tsv records path, atime,
    23	#          mtime and ctime (lstat, which moves no atime) for runs/**, logs/** and tmp/**, with rearmed_unread = 1 where
    24	#          the atime is still mtime - 1 ns;
    25	#   PR-M3  a REFUSED note names the read-only command that shows the cause (run_bs.py --preflight-only for that
    26	#          entry), never the attempt log.
    27	# BS wave runner, derived from the ECS runner (S2/r10round/ecs/tools/run_waves_ecs.sh, sha256 c007762c...): the same
    28	# crash handling, relaunch, lock, HALTED and VOID rules; the bias screen's queue, slots, nice and floors.  Runs ONLY
    29	# after <BS>/APPROVED, <BS>/criteria.txt and <BS>/SCREEN.json exist; every continuation still passes run_bs.py's own
    30	# preflight (which refuses on any unpinned or changed input: APPROVED pins criteria.txt, SCREEN.json and the tools).
    31	#
    32	#   run_waves_bs.sh            run (or resume) the queue
    33	#   run_waves_bs.sh --plan     print the queue and the commands; check nothing, launch nothing, write nothing
    34	#
    35	# OUTCOME-BLIND: while the queue runs, the runner reads only each attempt's exit code, run_meta.json (status, exit,
    36	# stop_reason, heartbeat, last_step) and the CHECK's exit code (read_bs.py --check).  It never opens an attempt's log,
    37	# a ledger, a probe or a checkpoint (the atime re-arm and snapshot use lstat and utime only: no file is opened).  Started detached (setsid nohup) by the coordinator; a harness-tracked watcher
    38	# reads only logs/run_waves_bs.log.  Nothing relaunches it automatically.  While logs/HALTED exists it refuses to start
    39	# (exit 2); it writes logs/HALTED whenever a halt (exit 2) or a VOID (exit 4) stops the queue; only the coordinator
    40	# removes it.
    41	#
    42	# The queue is SCREEN.json's (bs_common.load_screen: control and ONE intervention, at most 9 continuations), in its
    43	# order, run in bs_common.WAVE_SLOTS (4) slots at nice bs_common.WAVE_NICE (10): a slot that frees starts the next.
    44	#   - a fresh queue (no decision, no crash, no run folder) starts only with free disk >= bs_common.LAUNCH_DISK_BYTES
    45	#     (the 1.5 GiB floor plus 9 x 50 MiB), else it refuses (exit 2; nothing started).
    46	#   - before each start: free disk >= bs_common.DISK_FLOOR_BYTES (1.5 GiB), else PAUSED: no new start, the running
    47	#     ones go on, logs/PAUSED_disk names the shortfall; it resumes by itself once space is free.  The process table and
    48	#     the load are appended to logs/proctable.log at each start.
    49	#   - each attempt's output goes to logs/<name>.attempt<k>.log (never opened by the runner; it may print evaluation
    50	#     returns).  A crash's cause is read from run_meta.json's error and traceback.
    51	#   - as each exits, by its exit code:
    52	#       0: `read_bs.py --check <run>` (CHECK only).  Exit 0: COUNTED (stop reason "end") or STOPPED ("collapse").
    53	#          Exit 4: VOID: decided VOID, runs/<name> -> runs/<name>_void<k>; no new start; the runner exits 4 at the
    54	#          end.  Any other CHECK exit: CHECK ERROR, the folder left as it is, no new start, exit 2.
    55	#       5: the run reached its end but a post-run check failed (status "failed"): checked like 0; CHECK fails: VOID.
    56	#       2: REFUSED before any optimizer step: runs/<name> (if made) -> runs/<name>_refused<k>, no new start, exit 2.
    57	#       other: CRASH: runs/<name> -> runs/<name>_crashed<k>, logs/crash_ledger.tsv.  An EARLY crash (last recorded step
    58	#          below S + 131,072, or none) is not counted and halts new starts.  Any other crash is one of its own and is
    59	#          rerun at once from the start pair with the same arguments; a third own crash writes it to <BS>/lost.json.
    60	# Relaunch: logs/run_waves_bs.lock (waiting up to 30 s; another live runner: exit 3), waits while any of this BS's
    61	# run_bs.py processes is alive, then reads logs/decided.tsv and <BS>/lost.json; a runs/<name> found done is checked; one
    62	# found failed is checked as exit 5; one found refused is handled as exit 2; any other is a CRASH (counted only if its
    63	# run_meta says "crashed", under the early-crash rule).  A VOID in the ledger refuses the relaunch (exit 4).
    64	# When all are COUNTED, STOPPED or LOST and none is VOID: logs/ALL_DECIDED, then the full read (`read_bs.py <run>`,
    65	# the markers; refused by read_bs.py itself until all are decided) of each COUNTED or STOPPED continuation, WAVE_SLOTS
    66	# at a time at nice 10.  No scorer is run here (the criteria's, written and pinned before launch).  No push.
    67	# Exit codes: 0 all decided and read; 2 refused / halted; 3 another runner holds the lock; 4 VOID.
    68	# No redirection onto any path outside <BS> (stderr of probes goes to logs/runner_stderr.log).
    69	set -euo pipefail
    70	export PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 LC_ALL=C
    71	
    72	S2=S2
    73	BS_REAL=$S2/r10round/long_blind
    74	PY=$S2/venv/bin/python
    75	TOOLS=$BS_REAL/tools
    76	
    77	die() { echo "run_waves_bs: refused: $*" >&2; exit 2; }
    78	
    79	BS=$BS_REAL
    80	RUN_CMD=(nice -n 10 "$PY" -I -B "$TOOLS/run_bs.py")
    81	CHECK_CMD=("$PY" -I -B "$TOOLS/read_bs.py" --check)
    82	READ_CMD=(nice -n 10 "$PY" -I -B "$TOOLS/read_bs.py")
    83	PS_CMD=(ps -eo pid,ppid,ni,pcpu,pmem,etime,args --sort=-pcpu)
    84	ORPHAN_PATTERN="^$PY -I -B $TOOLS/[r]un_bs[.]py --arm "
    85	POLL=10
    86	LOCK_WAIT=30
    87	QUEUE_OVERRIDE=""
    88	SLOTS_OVERRIDE=""
    89	FLOOR_OVERRIDE=""
    90	LAUNCH_OVERRIDE=""
    91	SCORER_OVERRIDE=""
    92	# Test hook (tests/test_waves_bs.py): honoured only with BS_WAVES_TEST=1 and a root that is not <BS>.
    93	if [[ "${BS_WAVES_TEST:-}" == 1 ]]; then
    94	  [[ -n "${BS_ROOT:-}" ]] || die "BS_WAVES_TEST needs BS_ROOT"
    95	  [[ "$(realpath -m "$BS_ROOT")" != "$(realpath -m "$BS_REAL")" ]] || die "BS_WAVES_TEST may not use the real <BS>"
    96	  BS=$(realpath -m "$BS_ROOT")
    97	  read -r -a RUN_CMD <<< "$BS_RUN_CMD"
    98	  read -r -a CHECK_CMD <<< "$BS_CHECK_CMD"
    99	  read -r -a READ_CMD <<< "$BS_READ_CMD"
   100	  [[ -n "${BS_PS_CMD:-}" ]] && read -r -a PS_CMD <<< "$BS_PS_CMD"
   101	  ORPHAN_PATTERN=${BS_ORPHAN_PATTERN:-$ORPHAN_PATTERN}
   102	  POLL=${BS_POLL_SECONDS:-1}
   103	  LOCK_WAIT=${BS_LOCK_WAIT_SECONDS:-2}
   104	  QUEUE_OVERRIDE=${BS_QUEUE:-}
   105	  SLOTS_OVERRIDE=${BS_SLOTS:-}
   106	  FLOOR_OVERRIDE=${BS_DISK_FLOOR_BYTES:-}
   107	  LAUNCH_OVERRIDE=${BS_LAUNCH_DISK_BYTES:-}
   108	  SCORER_OVERRIDE=${BS_SCORER:-}
   109	fi
   110	RUNS=$BS/runs
   111	LOGS=$BS/logs
   112	LOST_JSON=$BS/lost.json
   113	DECIDED=$LOGS/decided.tsv
   114	CRASHES=$LOGS/crash_ledger.tsv
   115	HALTED_FILE=$LOGS/HALTED
   116	ERRLOG=$LOGS/runner_stderr.log
   117	
   118	# One source for the slots, the floors, the crash limit, the grid and the queue: bs_common (the queue from SCREEN.json
   119	# under the root; each queue line: arm seed name S E).  A missing or invalid SCREEN.json refuses (except in tests with
   120	# BS_QUEUE).
   121	COMMON_OUT=$("$PY" -I -B - "$TOOLS/bs_common.py" "$BS/SCREEN.json" "${QUEUE_OVERRIDE:+override}" <<'PYEOF'
   122	import importlib.util, sys
   123	s = importlib.util.spec_from_file_location("c", sys.argv[1]); C = importlib.util.module_from_spec(s)
   124	s.loader.exec_module(C)
   125	print(C.WAVE_SLOTS, C.WAVE_NICE, C.DISK_FLOOR_BYTES, C.MAX_CRASHES, C.LOST_SCHEMA, C.LAUNCH_DISK_BYTES, C.EVAL_FREQ,
   126	      C.EXIT_POST_CHECK, C.S, C.E, C.MAX_CONTINUATIONS, C.SCORER_FILE)
   127	if len(sys.argv) > 3 and sys.argv[3] == "override":
   128	    sys.exit(0)
   129	d, problems = C.load_screen(sys.argv[2])
   130	if problems:
   131	    print("SCREEN-PROBLEMS " + " | ".join(problems))
   132	    sys.exit(0)
   133	for arm, seed in C.queue_of(d):
   134	    print(arm, seed, C.run_name(arm, seed), C.S, C.E)
   135	PYEOF
   136	) || die "bs_common.py could not be read"
   137	read -r SLOTS NICE FLOOR MAX_CRASHES LOST_SCHEMA LAUNCH EVAL_FREQ POST_CHECK S_ALL E_ALL MAXN SCORER_FILE \
   138	  <<< "$(head -n 1 <<< "$COMMON_OUT")"
   139	SCORER=${SCORER_OVERRIDE:-$TOOLS/$SCORER_FILE}
   140	[[ "$NICE" == 10 ]] || die "bs_common.WAVE_NICE is $NICE; RUN_CMD runs at nice 10"
   141	if [[ -n "$QUEUE_OVERRIDE" ]]; then
   142	  IFS=';' read -r -a QUEUE <<< "$QUEUE_OVERRIDE"
   143	else
   144	  if grep -q '^SCREEN-PROBLEMS' <<< "$COMMON_OUT"; then die "$(grep '^SCREEN-PROBLEMS' <<< "$COMMON_OUT")"; fi
   145	  mapfile -t QUEUE < <(tail -n +2 <<< "$COMMON_OUT")
   146	fi
   147	(( ${#QUEUE[@]} >= 1 && ${#QUEUE[@]} <= MAXN )) || die "queue of ${#QUEUE[@]} (1 to $MAXN allowed)"
   148	[[ -n "$SLOTS_OVERRIDE" ]] && SLOTS=$SLOTS_OVERRIDE
   149	[[ -n "$FLOOR_OVERRIDE" ]] && FLOOR=$FLOOR_OVERRIDE
   150	[[ -n "$LAUNCH_OVERRIDE" ]] && LAUNCH=$LAUNCH_OVERRIDE
   151	declare -A S_OF=() E_OF=() ARGS_OF=() LOG_OF=()
   152	NAMES=()
   153	for line in "${QUEUE[@]}"; do
   154	  read -r arm seed name S E <<< "$line"
   155	  S_OF[$name]=$S; E_OF[$name]=$E; ARGS_OF[$name]="$arm $seed"; NAMES+=("$name")
   156	done
   157	
   158	if [[ "${1:-}" == "--plan" ]]; then
   159	  [[ $# -eq 1 ]] || die "--plan takes no other argument"
   160	  echo "slots $SLOTS at nice $NICE; disk floor $FLOOR bytes; launch floor $LAUNCH bytes; crash limit $MAX_CRASHES;" \
   161	       "early crash: last step below the attempt's load step + $EVAL_FREQ; an own crash reruns with" \
   162	       "--resume-from runs/<name>_crashed<k> (its newest complete saved pair, else S)"
   163	  echo "orphan pattern: $ORPHAN_PATTERN"
   164	  for name in "${NAMES[@]}"; do
   165	    read -r arm seed <<< "${ARGS_OF[$name]}"
   166	    echo "  ${RUN_CMD[*]} --arm $arm --seed $seed > $LOGS/$name.attempt<k>.log  (S ${S_OF[$name]}, E ${E_OF[$name]})"
   167	  done
   168	  echo "then: ${CHECK_CMD[*]} <run>; after all are decided: ${READ_CMD[*]} <run> (the markers; no scorer)"
   169	  exit 0
   170	fi
   171	[[ $# -eq 0 ]] || die "usage: run_waves_bs.sh [--plan]"
   172	[[ -f "$BS/APPROVED" ]] || die "no <BS>/APPROVED"
   173	[[ -f "$BS/criteria.txt" ]] || die "no <BS>/criteria.txt"
   174	[[ -n "$QUEUE_OVERRIDE" || -f "$BS/SCREEN.json" ]] || die "no <BS>/SCREEN.json"
   175	# PR-M4: APPROVED must pin the scorer as well (the criteria's PROVISIONAL rule needs tool_sha256["score_bs.py"], and
   176	# APPROVED is never edited after the first start); run_bs.py's preflight checks the other pins for each continuation.
   177	SCORER_PIN=$("$PY" -I -B - "$BS/APPROVED" "$SCORER" "$SCORER_FILE" <<'PYEOF'
   178	import hashlib, json, sys
   179	try:
   180	    d = json.load(open(sys.argv[1]))
   181	except Exception as exc:  # noqa: BLE001 - any unreadable APPROVED refuses
   182	    sys.exit(print(f"APPROVED does not parse ({exc.__class__.__name__})"))
   183	tp = d.get("tool_sha256") if isinstance(d, dict) and isinstance(d.get("tool_sha256"), dict) else {}
   184	key = sys.argv[3]
   185	try:
   186	    got = hashlib.sha256(open(sys.argv[2], "rb").read()).hexdigest()
   187	except OSError as exc:
   188	    sys.exit(print(f"tools/{key} unreadable ({exc.__class__.__name__})"))
   189	print("ok" if tp.get(key) == got else f"APPROVED tool_sha256[{key!r}] {tp.get(key)!r} != the file's {got}")
   190	PYEOF
   191	) || die "the scorer pin in APPROVED could not be checked"
   192	[[ "$SCORER_PIN" == ok ]] || die "$SCORER_PIN (APPROVED must pin tools/$SCORER_FILE: criteria, HOW THE COORDINATOR PINS)"
   193	
   194	# ------------------------------------------------------------------------------------------------------------ helpers
   195	sleep() { command sleep "$@" 9>&-; }
   196	
   197	note() {  # the runner's log line; the log file first, then stdout, which may be closed
   198	  local line
   199	  line="[run_waves_bs $(date -u +%Y-%m-%dT%H:%M:%SZ)] $*"
   200	  printf '%s\n' "$line" >> "$LOGS/run_waves_bs.log"
