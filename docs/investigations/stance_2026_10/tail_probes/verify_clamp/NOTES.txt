1. THE ACTION MAPPING AND THE OVERRIDE, CHECKED FROM THE ENV CODE AND AT RUN TIME
==================================================================================================================
[code read in policies/code_copy; measured: static_tail.py -> static_tail.txt; verify_sim.py -> out/*.jsonl,
compare.py -> compare.txt section 2]
- The code path.
  - shared/base_env.py step() calls _filter_action and then _scale_action, and writes data.ctrl.
  - The T. rex _filter_action keeps the clipped pre-filter command (_policy_action), then calls the base filter.
  - The base filter clips to [-1, 1].  Its state is seeded with the first post-reset action, then
    state += alpha (x - state), with alpha 0.386 at 10 Hz and dt 0.01.
  - _scale_action is the home-keyframe residual.
  - Under action_penalty_source "raw", the jerk, smoothness and saturation terms price _policy_action, which is the
    overridden command.  Energy prices the filtered one.
- The observation carries no action history (_get_obs: qpos[7:], qvel[6:], gravity, gyro, velocity, accelerometer,
  contacts, prey, command).  So the override reaches the policy only through the state, as D-9's did.
- Index 14 is tail_3_pitch_act, with trnid on the tail_3_pitch joint.  The tail_3 angle is observation index 6
  (qposadr 13 - 7).
- _scale_action maps action 0 / +0.5 / +1 to ctrl 0 / +0.1047 / +0.2094 rad [static_tail.txt].
- At run time: 73 overridden episodes (held 0, held 0.5, forced +1, the D-9 onset checkpoint, the start checkpoint).
  At every step, _action_filter_state[14] equals V and data.ctrl[14] equals V's mapping.  0 steps deviate; the maximum
  deviation is 0.0 [compare.txt section 2].
- The override is D-9's.
  - I read r10round/f2/copy_8737cd3d/environments/shared/reporting/episode_trace.py trace_episode (holds).
  - D-9's run header: deterministic, holds tail_3_pitch_act = 0, vecnormalize-frozen.
  - My own loader: PPO.load, the VecNormalize pickle unpickled directly, and the normalisation written out by hand
    with SB3's float32 cast.  On D-9's onset checkpoint at seeds 3042, 3050 and 3061 it gives D-9's return and window
    return exactly.  Held minus D-9 baseline: +70.32 / +33.68 / +50.12, as in d9_summary.json [compare.txt section 3].
- Why command +1 holds the tail at +5.2 deg, not 12 deg [measured, static_tail.txt].
  - The spring preload k x springref = 80 x 0.1815 = +14.52 N m.  It cancels the gravity torque on the joint at 0 deg
    (+14.49 N m).
  - So the equilibrium is set by the servo (kp 60) against the joint stiffness (k 80):
    q = 12 deg x 60 / 140 = 5.14 deg, plus 0.04 deg from gravity's angle dependence = 5.18 deg.
  - Servo torque is +7.1 N m against a +-50 N m force range: not saturated.
  - The runner's summary says "because of the spring and gravity".  More exactly, it is the spring's stiffness.
    Gravity is nulled by the preload.
