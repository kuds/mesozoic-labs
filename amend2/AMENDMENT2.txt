0. IN PLAIN WORDS

- The rule. THE ONE TEST compares the three phase-critic (PHASE) runs with the three concurrent switch-off (OFF) runs.
  It is only fair if the people starting the OFF runs had not seen any PHASE results yet; otherwise what they saw could,
  even without anyone meaning it, shape how the controls were started. The pinned rule does not try to judge whether a
  look mattered: any look at a PHASE run's results before the last OFF launch (an F2-START, REFETCH-START or SNAPSHOT
  line of a PHASE run) makes every OFF run launched after it NOT BLIND, and a NOT BLIND OFF run counts in THE ONE TEST
  as missing, at -infinity (criteria.txt lines 297-302 and 353-361; what is an opening: lines 371-373). A missing run
  always counts against the hoped-for result, so THE ONE TEST can then never read LOWER.
- What happened. At 17:44 UTC on 2026-11-01 the maintainer pasted the s60 PHASE run's notebook output into the chat to
  ask whether more results should be in the run folder (RUNLOG lines 902-903). It held rewards, episode lengths,
  distance and the checkpoint choice; no tail command, TD or ledger figure (RUNLOG line 902) [measured: RUNLOG text; what
  was on screen is the operator's record]. That is an opening under the rule (criteria.txt lines 371-373: a PHASE run's
  notebook output read is an opening, noted as a SNAPSHOT line; every OFF run launched after it is NOT BLIND), and it
  came before the three OFF launches (18:12, 18:20, 18:56 UTC). RUNLOG records more after it: possible views before
  the OFF launches (LIMITS (i)) and an order deviation between them (LIMITS (ii)). Under the pinned reading all three OFF runs are NOT BLIND, at -infinity, and THE ONE TEST reads
  p = 20/20 whatever the six TDs: every other 3 + 3 split holds at least one -infinity, so its 3-sum ranks below the
  PHASE sum (criteria.txt lines 297-302); it cannot pass [measured: the dry run on RUNLOG reads all three OFF runs NOT
  BLIND; the pinned p is 20/20 in every synthetic test with the line, a LOST PHASE run included (tests (a), (d), (e),
  M3); inferred: the rank argument, for every TD value].
- "Report only" looks. criteria.txt allows report-only looks at a run (SNAPSHOT lines that decide nothing) only AFTER
  every OFF run's LAUNCH line is in RUNLOG (lines 374-377). Before that point the rule has no report-only kind of look:
  any look is an opening (lines 371-373). The 17:44 look came before the OFF launches, so the pinned rule cannot read it
  as report only. Looks after 18:56 UTC would have been report only and changed nothing.
- The two readings. The pinned reading applies the rule as written and stays the round's reading of record; it is
  printed first and whole. The DEVIATION reading computes THE ONE TEST as if the three OFF runs were blind: it sets
  aside RUNLOG line 902, the only recorded opening before the OFF launches (see LIMITS). It is printed second, under its
  own header, flagged as not the pinned reading. If the deviation reads LOWER and the pinned one does not, the honest
  summary is: the pre-registered test could not be passed because of a procedural slip; a reading decided after the
  slip, which assumes the slip had no effect on the OFF runs, reads LOWER.

- Definition. The DEVIATION reading of THE ONE TEST is THE ONE TEST line that the pinned score_pc.py, unchanged, prints

  byte copy of the round's RUNLOG elsewhere is refused too); the first two checks come before the --out check, so a
  refused call reads nothing of the round. The round's deviation reading therefore always drops exactly line 902

- Line numbers kept. The line's content is removed and its line feed kept, so every other line keeps its bytes and its

  established, views of three pc_s60 01_stance files (stance_gate_probe_constant.txt 17:50:58Z, gate_verdict.json

  folder's web interface or reads by the notebook [paraphrase]) after 17:44 and before every OFF launch (18:12 the first). They were not written as a SNAPSHOT
  line because the 17:44 opening already governed pc_s60 (line 905: "its first opening governs"). The scorer reads only
  RUNLOG's SNAPSHOT, F2-START and REFETCH-START lines, so these views enter neither run; computing THE ONE TEST as if
  the three OFF runs were blind sets them aside too. What they showed is not on record [measured: RUNLOG line 905].
- (ii) An order deviation after the opening. RUNLOG line 910 records that OFF s80 was launched (18:20) before OFF s42
  (18:56), against THE ORDER (the OFF runs start in seed order s60, s42, s80); it came after the 17:44 opening. No
  scoring rule reads the order (the scorer prints each seed's PHASE-OFF start gap, report only) [measured: RUNLOG lines
  907, 910, 911, 923].
- (iii) The pinned reading's test is empty by construction. With the three OFF runs NOT BLIND, at -infinity, the
  pinned p is 20/20 whatever the six TDs (section 0): the pinned reading cannot read LOWER, so "both readings agree" can
  only mean the deviation reads NOT SEPARATED too; it says nothing about whether the look mattered [measured: every
  synthetic test with line 902; inferred: the rank argument].
- (iv) Post hoc relative to the opening, fixed before the data. The deviation was decided about 20 hours after the 17:44
  opening (RUNLOG line 949, 2026-11-02 13:52 UTC), by people who knew what the opening showed (rewards, lengths,
  distance of PHASE s60; no TD): it is not pre-registered relative to the opening. It was decided before any F2 file and
  before any tail-command, TD or ledger figure of any run was seen [measured: RUNLOG lines 902, 949; for the line-905 views this rests on line 949's statement, which names the
  tail-command figure only, and their content is not on record; RUNLOG holds no
  F2-START or REFETCH-START line (952 lines, read by the dry run at 2026-11-02 15:04 UTC); inferred: that nothing shown
  at 17:44 reveals a TD]. Even so it reads LOWER only on complete separation: THE ONE TEST is an exact one-sided
  permutation test over the 20 ways to split six TDs 3 + 3; p = 1/20 = 0.05 only when every PHASE TD is below every OFF
  TD; any other placement gives p >= 2/20, above alpha 0.05 [measured: synthetic tests (a) and (e): complete separation
  1/20, one OFF TD below the PHASE TDs 4/20]. Under no effect and exchangeability the chance of complete separation is
  1/20 [inferred from the test's definition].
- "As if blind" is an assumption, not a repair. The rule exists because a look cannot be shown to have had no effect.
  The deviation assumes the looks (line 902, and the views of line 905) had no effect on the OFF runs; the support for
  that is that their launches were fixed by procedure and passed their launch checks (section 2) [inferred: the checks
  cover configuration, not every possible influence].
- Do not choose between the readings after seeing them. The pinned reading is the record, printed first; the deviation
  is printed beside it whatever either says.
- Every caveat of THE ONE TEST in criteria.txt (concurrent control, the within-seed dependence A5, GPU nondeterminism,
  TD's form chosen with STANCE6's values in view) applies to both readings.
- An OFF run that is LOST, not COMPLETE or never launched stays missing (-infinity) in both readings; a PHASE run that
  is LOST stays at +infinity in both: the deviation removes only the opening [measured: synthetic tests (d), M3].
