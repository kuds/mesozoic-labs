  If the r9 banks differ between runs, procedure X is done per distinct bank.
- Procedure X (r10 networks + r9 bank STATES; no r9 series; no simulation):
  - For each r10 checkpoint of s42, s60, s80 in the F2 copies (numbered checkpoints + finals, 37 in all), load with
    the harness loader (sealed code copy, CPU, normaliser frozen) and compute the raw mu[14] on the r10 bank's
    statue_settled rows (y10, mean of the rows) and on the r9 bank's statue_settled rows (y9, mean of the rows).
  - Validation: y10 must equal the r10 probe's recorded bank_ss at that step to <= 1e-5 (finals excepted, as in
    early_warning section 0).  If the r9 bank's observation length differs from the network's input, X is void.
  - Fit y9 = a + b * y10 by least squares over the 37 checkpoints.  thr9 = a + b * 0.150 (also report
    a + b * 0.186).

    reported, flagged "transfer poor", and P1's result is read as a test of the number 0.150 on a different bank,
    not of the signal.

  - Limitation [inferred]: the translation goes through r10 networks; r9 networks may map the two banks

5. COUNTING
------------------------------------------------------------------------------------------------------------------
- For each rule x run x outcome:
  - TRUE WARNING: the rule fires at step f and the outcome occurs at step o with f < o.  LEAD = o - f (steps).
    "Early" = lead >= 524,288 (4 evaluation intervals).
  - LATE: fires at f >= o.  Counted as a MISS for that outcome.
  - MISS: never fires, outcome occurs.
  - FALSE ALARM: fires, outcome never occurs within the ledger's recorded span.  Probe rows after the last ledger
    evaluation are ignored (no outcome can be seen there).  The steps from the firing to the ledger's end are
    reported (censoring: a late firing in a short run is weak evidence either way).
  - TRUE NEGATIVE: never fires, outcome never occurs.
- Only the first firing defines the lead.  Also reported: whether the signal fell back below its threshold before
  the outcome, later re-crossings, and each signal's maximum before the outcome and over the run.
- P2 and S4 are CMD_L itself; their relation to PARK (O4) is mechanical and is reported but not counted as evidence.
- Per-rule verdict on O1 (primary):
  - HOLDS: a true warning in every r9 run with an O1, and no O1 false alarm in any r9 run without one.
  - PARTIAL: at least one true warning and at most one O1 false alarm.
  - FAILS: otherwise.
  The same tally is reported for O2, O3 and O4.
- Sample size: 5 runs (n positives set by the ledgers).  No rate is estimated with useful precision; exact counts
  are reported (e.g. 2/2 warned has a 95% Clopper-Pearson interval on sensitivity of [0.16, 1]; 0/3 false alarms
  has an upper bound of 0.71).  Everything is correlational.
