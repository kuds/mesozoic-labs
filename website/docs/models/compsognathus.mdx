# Compsognathus Longipes

The anatomical proxy has a 1.0 kg assumed mass, 14 actuators, a long articulated tail, and 56 state observations (the last three are the Phase C body-relative command segment, zero under `command_mode = "none"`).

The stance node certifies stance quality, not reward: since physics r2 its gate is `stance_quality/v2`, which judges
every episode of a 40-episode panel on the floor's force under each foot (no hop or stomp at reset, no long two-foot
flight or hard landing later, both feet planted, the pad and all three toes of each foot loaded, level pads not stood
on an edge, no drift, no actuator held at its limit) and certifies the stance when at least 37 of 40 are clean. A soft, low bounce, or a foot
that lifts for less than half of a 20 ms control step, can still pass it, so a trained stance is also checked by hand. Since the same revision the leg actions are
softened near the standing pose (a soft-cubic residual that keeps both ends of each joint's range), so the small
exploration noise PPO starts with no longer topples the standing animal.

## Training

Select **Compsognathus Longipes** in the SB3 training notebook. Its manifest (`configs/compsognathus/stages.toml`) declares four nodes, all published deliverables: `stance` (stand), `recovery` (stand, warm-started from stance), `locomotion` (walk, warm-started from stance) and `behavior` (hunt — the non-contact target-reach task, warm-started from locomotion). The notebook's `BEHAVIOR = "hunt"` default resolves to the behavior node here as for every species. The final task requires an upright, slow arrival within 8 cm of the target, measured at the pelvis in the ground plane.

```bash
python -m pip install -e ".[train]"
python -m environments.shared.train --species compsognathus train --stage 1

# The advancing stages in manifest order; reuse an earlier run's certified stance and walk
python -m environments.shared.train --species compsognathus curriculum \
  --trunk-from logs/<earlier_run> --output-dir logs/<new_run>
```

Actions are residual joint-position commands around a preloaded standing pose. The control rate is 50 Hz and the default episode horizon is 20 seconds. Simulator state and target coordinates are privileged MLP inputs; the RGB camera is available separately for rendering. These policies are not onboard camera controllers.

The initial configurations and short integration runs establish training compatibility. They do not establish learned walking, behavior convergence or hardware readiness. The zero-action standing baseline should be measured before tuning. Every node is judged on its own and its verdict written to `gate_verdict.json` beside the handoff checkpoint; a later run reuses it only under the reuse rule (a passed verdict, the same task digest and plant, chained by the parent's checkpoint digest) — see [Behavior Recipes](/docs/training/recipes).

See the [model and training guide](https://github.com/kuds/mesozoic-labs/blob/main/environments/compsognathus/README.md) for mechanical assumptions, sensor details and validation commands.
