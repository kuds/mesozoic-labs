WHAT IT MEANS [inferred]
 - Why the critic values a raised tail: four reward terms switch on at step 200 and the observation has no clock, so
   the true value depends on a hidden phase; the policy's slow tail creep after each reset makes the tail angle a
   clock; a phase-blind critic fitted to these returns gives the tail a positive slope that the returns do not
   support within a phase; the policy gradient follows it, a higher command lengthens and enlarges the creep, and
   the clock gets better: a loop.
 - On the maintainer's question, why blind the critic to one aspect of the robot: it is a clean causal test and a
   working stopgap, not a cure.  It removes the one channel through which the tail's own action changes the
   critic's estimate (BS2: no climb; here the blinded critic's tail push is -0.0007), but it leaves the cause: the
   blinded critic still makes the same phase error (+0.10), the phase is still decodable from the other joints, the
   same signature appears on s80's neck, and in one of four blinded runs the next tail joint started to climb.
   A root-cause fix would remove the hidden phase from the value target: give the critic alone the step index or a
   settled flag (the actor need not see it), or make the gated terms stationary (pay from step 0, or centre them on
   a reference that is not captured at step 200).  Offline, a value that sees the phase has a tail slope <= 0 and
   pushes the tail command down, the same direction as the realised returns.  No training run has tested this.
