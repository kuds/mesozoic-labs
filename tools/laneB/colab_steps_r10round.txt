THE ENDING PROCEDURE (liveness or configuration only, never an outcome; for every runtime of the round)

     .ipynb to <ROUND>/outputs/<RUN_ID>.ipynb) if the browser still shows it. A finished run releases its runtime

 (b) No cell is running (Run all stopped, a dead kernel, a halt that did not release),
 (c) a STALL: 2 hours with neither a progress.json rewrite (Drive's file view) nor a new notebook output line, or
 (d) a launch-check stop:
     write the TRIGGER-b / TRIGGER-c line with its time (a launch-check stop: STOP and TRIGGER-d at one time); then
     Runtime > Interrupt execution (Restart session if it does not stop); File > Download .ipynb to

         from google.colab import drive; drive.flush_and_unmount()

 A run has ENDED when its runtime is deleted so or noted found gone. No cell is run in a runtime after its Run all

 Suggested liveness check (not a rule): Runtime > Manage sessions every 30 min in a run's first 2 h, every 2 h after;
