4. StopAtEnd (G2), in run_ecs.py
- _on_step returns False when num_timesteps == E. Every other callback has run on that step, so the evaluation and
  the checkpoint at E exist; no update is made on the rollout ending at E (HS 4.3). It refuses if num_timesteps ever
  passes E. The end state is the stage1_<E>_steps pair.

5. NO-UPDATE MODE (for V2-V4 only; never for a continuation)
- --no-update replaces the model's train() with a function that counts its calls and returns; --until STEPS stops at
  that step. The parameter and Adam digests at the end must equal the start's, or it exits 1.

6. <ECS>/tools/read_ecs.py (G4, G7)
- R1: runs the pinned M5 unchanged ("ledger_r10round.py <ledger> --E <E> --json <out>"); from its per-evaluation
  output keeps the evaluations with timesteps in (S, E]; POSITIVE; first ANY-flagged step; flagged count; ANY and
  TAIL alarms and TAIL flags in the window; C6's verdict.
- R2: policy_probe.npz (allow_pickle False), rows with update_timesteps in (S, E): M6's arrays for all 15 actuators,
  std_per_actuator; window means and maxima.
- R4: ent_coef and learning_rate rows in (S, E) against the parent's probe at the same update_timesteps (A: float32
  equal; B: ent_coef 0.0, learning_rate equal); the row count must be (E - S) / 8,192 - 1 = 191.
- R3: M1's m1_summary.json for the E pair: CMD per actuator, flags, falls.
- Prints every value with the file and sha256 it came from; exit 0 read, 2 input error.

7. <ECS>/tools/score_ecs.py
- Each continuation: COUNTED, STOPPED (positive or censored), LOST or VOID, from run_meta, read_ecs and RUNLOG's
  LOST declarations; the two tables; the exact stratified test, two-sided, in exact fractions (the code of
  <ECS>/v1/table_e_ecs.py, moved into the tool); the reading line; the INFORMATIVE note; every report-only line;
  PROVISIONAL items; "incomplete" until all 24 are decided. Exit 0 final, 3 provisional or incomplete, 2 input error.

8. <ECS>/tools/run_waves_ecs.sh (G8; ported from DD43's tools/run_waves.sh)
- Refuses without <ECS>/APPROVED. A queue in this fixed order, 3 slots at nice 10 (D10): for j = 1..6: s42 A j,
  s42 B j, s80 A j, s80 B j (seed j of each arm's list). The disk floor before each start.
- The crash rule of the criteria: a non-zero exit or a half-way folder found at (re)launch moves it to
  <name>_crashed<k> and reruns it with the same arguments; a container restart is not counted toward the three.
- After each COUNTED or STOPPED continuation: M1 (m1 --copy <ECS>/code --zip/--pkl the stage1_<E>_steps pair, or
  a STOPPED one's stage1_final pair, --stage-config its stage_config.json --out <ECS>/traces/<name>), one at a time
  at nice 19.
- Logs under <ECS>/logs/; no push, no Drive (D15).
